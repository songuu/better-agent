### 观测与发布追加验证

在线质检应验证数据来源、采样范围、评估器输入/输出、Run 关联、重复评估和失败状态；网页/API/SDK/A2A/企业渠道应分别验证发布对象、身份、取消和历史版本解析。Agent 版本回滚、专门记忆生命周期、节点级 token/成本目前是 **U**，不是已证实不存在；不能从知识文件回滚或数据库持久存储外推这些协议。

## 获取与闭环规则

每项补齐后必须新增以下三类证据，而不是只更新表格：

1. 来源快照或可复查链接；
2. 兼容规格（字段、限制、错误和安全边界）；
3. 自动化夹具或人工验收步骤，并标明适用的部署画像。

对 `R-A1`~`R-A12` 还必须记录实验的产品版本、Workspace 初始化状态、调用身份、模型/资源版本和采集时间。单张截图、单次自然语言输出或无法复现的 UI 观察都不足以升级为协议；未证实时应保留为“未知”，继续使用 ADR-001~004、Flow IR 与 Agent Release 契约中的安全自定规格。
