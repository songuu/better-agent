| LLM | 模型·创造性·提示词(AI生成/优化/透视图/结构化编辑器)·上下文(role/content JSON)·输出格式(文本\|JSON，OpenAI 系)·变量控制模型·深度思考开关·思考过程开关·多模态·异常设置 |
| 文档/问答知识库 | 知识库·标签(AND/OR)·查询方式(混合\|关键词\|语义)·查询关键词·最大查询结果数·结果重排·输出方式(文本\|JSON)·查询范围(全部文件\|仅查询指定文件-AI选择文件\|属性筛选)·解析PPT图片·异常设置·资源查看 |
| 多模态知识库 | 查询/新增/更新 文件·图片·视频；以图命中；新建文件/更新文件随类型变化 |

| CODE（JavaScript & Python） | main 入口必需·输出必须可序列化·CommonJS require·内置包·betterAI.store/session/agent·betteryeah SDK 五模块·异常设置·Code AI 编写助手·全屏多开 |

| Loop循环 | 2024-04-19 |
| 条件循环 | [终止循环] 条件 + 最大循环次数防死循环 |

## 5. 知识库

三类库：**文档知识库 · 问答知识库 · 多模态知识库**（2024-06-27 问答与文档拆分；2025-03-20 多模态上线）

```
库列表（列表式管理·标签·收藏·关联应用数量·直接删除·复制到本/其他空间-异步）
└─ 库详情
   ├─ 上传：本地文档(通用文档解析13格式 | 视觉文档解析8格式) · 手动输入 · 网页获取
   │        · 视频上传(MP4/MOV/WMV/FLV/AVI/WEBM/MKV，≤150MB，≤5个) · 知识抓取插件
   │        · 飞书一键同步(绑定飞书数据源→登录飞书账号→选文档/知识库) · 钉钉文档 · 语雀
   ├─ 分段管理
   │  ├─ 自动分段：Word类(标题+段落,>500字切) · PPT类(一页一段) · Excel(行+表头)
   │  │            · 通用类(\n\n,>500字切) · QA分段 · JSON分段
   │  ├─ 自定义分段：分段标识符(支持转义字符) + 每段最长字数
   │  ├─ FAQ分段：问题开始的字符 + 每段最长字数
   │  ├─ 上传时预分段
   │  ├─ 段落编辑：显示态/编辑态分离 · 可视化拆分合并 · 在上方插入段落
   │  │            · 图片/视频 复制粘贴上传 · 附件上传 · 关键词编辑
   │  ├─ 段落一键定位（输入段落编号跳转）
   │  └─ Embedding 异常：标记 → 手动重分段 | AI一键处理
   ├─ 元属性（默认自动提取 + 自定义，单文档可编辑值）
   ├─ 知识标签（≤9 个；编辑保存含未成型输入）
   ├─ 近义词（知识实体词 1 个≤20字 + 近义词≤25个≤20字，逗号/回车分隔；批量模板）
   ├─ 命中测试（测试文本 + 选择标签 + 查询方法 + 结果重排 + 查询结果数；渲染图片/表格/公式）
   ├─ 操作记录（查看操作记录：上传/更新/删除）
   ├─ 版本控制（手动新增版本 + 历史版本一键恢复，恢复时自动存当前为新版本）
   ├─ 有效期（库休眠机制；5个月未用过期+恢复；问答知识有效期区间）
   └─ 问答库专属：xlsx 模板 · 批量导入/更新/全部替换 · 相似问题 · 导出问答知识
```
